# 있템 등록하기

가지고 계신 물건을 「있템」으로 등록하는 방법입니다.

## 등록하는 순서

1. 있템 목록 화면에서 **있템 추가**로 들어갑니다.
2. 물건 **이름**을 입력합니다.
3. **카테고리**를 칩 목록에서 고릅니다. 이미 쓰신 카테고리가 칩으로 나오니 눌러서 고르시면 됩니다.
4. 필요하면 수량, 사용기한, 메모, 상태를 입력합니다.
5. 저장하면 있템 목록에 나타납니다.

## 무엇이 필수이고 무엇이 선택인가요

있템에 입력하는 항목은 다음과 같습니다.

**꼭 입력해야 하는 것**
- 이름
- 카테고리
- 수량 (비워 두시면 자동으로 1이 들어갑니다)
- 구매일 (등록하시는 날짜가 자동으로 들어갑니다)

**입력하지 않으셔도 되는 것**
- 사용기한
- 메모

**상태**는 미개봉, 사용중, 다 씀 중에서 고르시며, 고르지 않으시면 미개봉으로 저장됩니다.

## 카테고리는 왜 꼭 넣어야 하나요

카테고리는 있템을 등록하실 때 **반드시 입력해야 하는 항목**입니다. 비워 두시면 저장되지 않습니다.

카테고리로 목록을 걸러 보고 찾으실 수 있게 하기 위해서입니다. 카테고리가 비어 있는 물건은 나중에 목록에서 찾기 어려워집니다.

카테고리는 직접 정하시는 자유로운 이름입니다. 정해진 목록이 따로 있지 않고, 한 번 쓰신 이름이 다음부터 칩으로 나와 다시 고르실 수 있습니다.

**한 가지 예외가 있습니다.** 위시에 담아 두신 물건을 「샀어요 · 있템으로」로 옮기실 때는, 위시 쪽에 카테고리가 없었다면 비어 있는 채로 넘어옵니다. 카테고리가 없다는 이유로 옮기는 것이 막히지는 않습니다.

## 수량과 상태에 어떤 규칙이 있나요

**수량**은 1 이상의 정수만 입력하실 수 있습니다. 0이나 음수, 소수점이 있는 값은 저장되지 않습니다. 비워 두고 저장하시면 자동으로 1이 들어갑니다.

**상태**는 미개봉, 사용중, 다 씀 세 가지뿐입니다. 이 셋 외의 값은 저장되지 않습니다.

목록에서 상태는 점과 색상 배지로 보이고, 수량은 상자 아이콘과 숫자로 보입니다.
