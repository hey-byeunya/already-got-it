# 시작하기 — 가입 · 로그인 · 비밀번호

「이미 있어」를 처음 쓰실 때 필요한 것만 모았습니다.

## 회원가입하기

회원가입 화면에서 이메일, 비밀번호, 닉네임을 입력하시면 됩니다.

1. 이메일과 비밀번호를 입력합니다.
2. **닉네임을 2자 이상 20자 이하**로 입력합니다. 닉네임은 필수 항목이라 비워 두면 가입이 되지 않습니다.
3. 이용약관과 개인정보 처리방침 **동의 체크박스에 체크**합니다. 체크하지 않으면 가입 버튼이 진행되지 않습니다.
4. 가입을 마치면 입력하신 주소로 인증 메일이 갑니다. 메일의 링크를 눌러 인증을 마친 뒤 로그인해 주세요.

가입 직후 로그인 화면으로 돌아오면 방금 쓰신 이메일이 자동으로 채워져 있습니다. 다시 입력하지 않으셔도 됩니다.

## 로그인하기

로그인 화면에서 가입하신 이메일과 비밀번호를 입력하시면 됩니다. 이메일 인증을 마치지 않으셨다면 인증 메일의 링크를 먼저 눌러 주세요.

로그인하지 않은 상태로 목록 화면 주소를 열면 로그인 화면으로 이동합니다. 사용하시던 중에 로그인이 만료된 경우에도 오류 화면 대신 로그인 화면이 나타나니, 다시 로그인하시면 하던 자리로 돌아가실 수 있습니다.

## 비밀번호를 잊으셨을 때

비밀번호는 재설정하실 수 있습니다.

1. 로그인 화면에서 **「비밀번호를 잊으셨나요?」**를 누릅니다.
2. 가입하신 이메일 주소를 입력하고 보냅니다.
3. 받으신 메일의 재설정 링크를 누릅니다.
4. 새 비밀번호를 입력해 저장합니다.

재설정 링크는 시간이 지나면 만료됩니다. 링크를 눌렀을 때 만료되었다는 안내가 보이면, 1번부터 다시 하셔서 새 메일을 받아 주세요.

## 로그아웃하면 무엇이 지워지나요

로그아웃하시면 브라우저에 남아 있던 이전 로그인 정보가 모두 지워지고 화면이 새로 고쳐집니다. 그래서 같은 브라우저에서 곧바로 다른 계정으로 로그인하셔도 **이전 계정의 물건 목록이 잠깐이라도 보이지 않습니다.**

다만 로그인 화면의 **이메일 저장 값은 그대로 남습니다.** 다음에 로그인하실 때 편하시도록 남겨 둔 것입니다.

등록하신 물건 자체는 로그아웃한다고 지워지지 않습니다. 다시 로그인하시면 그대로 있습니다.
