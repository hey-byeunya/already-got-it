# 계정과 내 데이터

어떤 정보가 저장되는지, 로그인 없이 어디까지 보실 수 있는지에 대한 안내입니다.

## 어떤 정보가 저장되나요

계정에는 가입하실 때 입력하신 **이메일과 닉네임**이 저장됩니다.

등록하신 물건은 계정별로 따로 보관되며, **본인 계정으로 로그인하셨을 때만** 보입니다. 다른 사람에게 목록이 보이지 않습니다.

있템에는 이름, 카테고리, 수량, 구매일, 사용기한, 메모, 상태, 다 씀으로 바뀐 날짜가 저장됩니다. 위시에는 이름, 카테고리, 참고 링크, 메모, 담은 날짜가 저장됩니다.

## 로그인 없이 둘러보기

가입하지 않으셔도 화면이 어떻게 생겼는지 미리 보실 수 있습니다.

미리보기 화면에서는 **예시 데이터**가 보입니다. 실제 계정의 물건이 아니고, 이 화면에서 입력하신 내용은 **저장되지 않습니다.**

실제로 물건을 등록하고 보관하시려면 회원가입 후 로그인해 주세요.

## 다른 계정으로 바꿔서 쓸 때

같은 브라우저에서 계정을 바꿔 쓰셔도 안전합니다. 로그아웃하시면 이전 계정의 정보가 브라우저에서 지워지고 화면이 새로 고쳐지기 때문에, 곧바로 다른 계정으로 로그인하셔도 **이전 계정의 목록이 잠깐이라도 보이지 않습니다.**
