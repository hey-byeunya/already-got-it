# 찾기와 D-day 배지

물건을 찾는 방법과, 목록에 보이는 D-day 배지의 뜻입니다.

## 이름이나 카테고리로 찾기

목록 화면의 검색창에 물건 **이름**이나 **카테고리**를 입력하시면 걸러서 보실 수 있습니다. 있템 목록과 위시 목록 양쪽에서 쓰실 수 있습니다.

카테고리로 거르실 때는 검색창 대신 카테고리 칩을 눌러 고르셔도 됩니다.

## D-day 배지 네 가지

있템 목록은 **사용기한이 임박한 것부터** 위에 보이도록 정렬됩니다. 사용기한을 적지 않으신 물건은 목록 뒤쪽에 놓입니다.

각 물건에는 사용기한까지 남은 날을 알려 주는 배지가 붙습니다. 배지는 네 가지입니다.

| 배지 | 뜻 |
|---|---|
| **임박** | 사용기한이 **7일 이내**로 남았습니다 |
| **지남** | 사용기한이 이미 지났습니다 |
| **여유** | 사용기한까지 8일 이상 남았습니다 |
| **기한 없음** | 사용기한을 입력하지 않으신 물건입니다 |

배지는 색상과 아이콘으로 구분되어 한눈에 보입니다.

## 어제 본 숫자와 오늘 숫자가 다른 이유

D-day 숫자는 **저장해 두는 값이 아니라, 목록을 여실 때마다 오늘 날짜를 기준으로 새로 계산하는 값**입니다.

그래서 하루가 지나면 남은 날짜가 하루 줄어듭니다. 어제 「D-8 · 여유」였던 물건이 오늘 「D-7 · 임박」으로 보이는 것은 정상입니다. 물건 정보가 바뀐 것이 아닙니다.
